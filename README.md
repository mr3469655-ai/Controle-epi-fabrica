# 🏭 Controle de EPI - Fábrica

Sistema desenvolvido em Portugol para controle de distribuição de Equipamentos de Proteção Individual (EPI) em ambiente fabril.

## 🎯 Objetivo
Controlar a quantidade de EPIs retirados por funcionário, garantindo o uso consciente e evitando desperdícios.

## ⚙️ Como funciona
- O usuário digita o nome do funcionário
- Informa a quantidade de EPIs retirados
- O sistema verifica:
    - Até 3 EPIs: Liberado ✅
    - Acima de 3 EPIs: Alerta de atenção ⚠️

## 💻 Tecnologia
- Portugol Studio
